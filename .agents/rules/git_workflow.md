# Git Workflow Rule

Whenever the user asks for a `git commit` or git commit message:
Always provide the complete 3-step Git terminal sequence formatted in a single shell / bash code block so the user can easily run or copy it with one click:
1. `git add .` (or specific files)
2. `git commit -m "..."` (conventional commit message)
3. `git push` (or `git push origin <branch>`)

Ensure the commands are formatted cleanly in an executable code block for quick terminal copy/execution.
